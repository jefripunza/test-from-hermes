Awal — Hermes Agent
Install Hermes Agent di WSL
Install base Hermes Agent via pip install hermes-agent. Python venv dibuat di ~/.hermes/hermes-agent/venv/. Source code di ~/.hermes/hermes-agent/.
installvenv
Awal — Provider & Model
Konfigurasi 9ROUTER & Model AI
Setup provider OpenRouter via proxy pribadi https://ai.jefripunza.com/v1 dengan model agent. Semua LLM calls lewat endpoint sendiri. 9ROUTER_API_KEY disimpan di ~/.hermes/.env.
providermodel
Awal — WebUI
Setup Hermes WebUI
Clone & deploy hermes-webui dari repo github.com/nesquena/hermes-webui ke ~/apps/hermes-webui/. Berjalan di 0.0.0.0:8787.
webuifrontend
🔄 Systemd & Auto-Start
Awal — WSL systemd
Aktifkan systemd di WSL
Set systemd=true di /etc/wsl.conf. Aktifkan loginctl enable-linger biar user service jalan tanpa session login.
systemdwsl
Awal — Gateway & WebUI Daemon
Systemd Services: Gateway + WebUI
hermes-gateway.service — gateway daemon Hermes.
hermes-webui.service — WebUI server di port 8787.
Keduanya auto-start pas WSL boot.

Tahap 2 — OpenViking
Install OpenViking Memory Provider
Server memory lokal pakai openviking-server dengan embedder lokal bge-small-zh-v1.5-f16 via llama-cpp-python. Berjalan di 127.0.0.1:1933, dimensi embedding 512.
memoryembedding
Tahap 2 — Integrasi Hermes
Konfigurasi Memory Provider
Set memory.provider=openviking di Hermes config. Environment OPENVIKING_ENDPOINT=http://127.0.0.1:1933. Hermes bisa search & store memory via OpenViking.
integrasi

🔒 Security Layer
Tahap 3 — Go Auth Proxy
Reverse Proxy dengan Basic Auth (Go)
Build reverse proxy di Go: port 8888 → WebUI 8787, port 8889 → OpenViking 1933. Basic Auth dari auth.json — hot-reload (bisa edit tanpa restart). Source disimpan di ~/apps/hermes-proxy/main.go.
authproxygolang
Tahap 3 — Fix CORS
CORS Headers & Host Forwarding
Fix Cross-origin mismatch dengan preserve req.Host di Go proxy. Tambah CORS headers: Access-Control-Allow-Origin: *. WebUI set HERMES_WEBUI_TRUST_FORWARDED_HOST=1.
corsfix
Tahap 3 — Dual Proxy Services
Systemd: Proxy WebUI + Proxy OpenViking
hermes-proxy.service — port 8888 → WebUI.
hermes-proxy-openviking.service — port 8889 → OpenViking. Keduanya auto-start, basic auth sama.
daemonauth
